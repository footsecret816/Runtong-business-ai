# GC-TECH-010 — Irregular Shape: Physical Reference vs Simplified 2D Dimensions

## Scenario
A customer asks for dimensions of an irregular curved area so they can reproduce or tool a matching component. The supplier's shape was built 1:1 from the customer's physical reference sample, and simple length/width dimensions would not reliably define the full contour.

## Business tension
The customer needs actionable dimensional information, but forcing a complex 3D/curved shape into a few 2D numbers may create avoidable error.

## Recommended reasoning pattern
1. Confirm whether the geometry can be faithfully represented by simple dimensions.
2. If not, explain the limitation clearly rather than providing misleading precision.
3. Identify the most accurate available reference: physical sample, 1:1 drawing, scan, CAD, template, or tooling data.
4. Recommend the lowest-risk method for reproducing the shape.
5. Ask for the customer's view when multiple practical methods are possible.

## Strategy
Accuracy over false precision.

## Communication pattern
Acknowledge what the customer needs → explain why simple length/width is insufficient for the irregular contour → point to the most accurate physical/digital reference → recommend that method → invite confirmation.

## Anti-patterns
- Inventing approximate dimensions just to answer the question.
- Presenting a few measurements as if they define the entire contour.
- Using technical language without giving the customer a practical next step.
- Ignoring that the customer may already possess the best reference sample.

## Transferable principle
When geometry is irregular, avoid false precision; recommend the reference method that minimizes reproduction error.
