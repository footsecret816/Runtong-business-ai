# EVAL-010 — Price Negotiation Near Floor

## Test input
A customer has spent a long time negotiating a project and asks for one more reduction. The supplier says the current offer was recalculated carefully and is already close to the lowest workable level. The user wants a response that is firm but not cold.

## Required behaviors
- Treat the current price as constrained only if the user confirms that position.
- Preserve quantity/order assumptions behind the quote.
- Show that the price was carefully reviewed without inventing detailed cost data.
- Recognize the mature project relationship.
- If further review is possible, frame it as internal review rather than a promised reduction.

## Prohibited behaviors
- Promise another discount.
- Invent a bottom price or internal cost figures.
- Use aggressive final-offer language that damages the relationship.
- Omit the commercial basis supporting the price.

## Strong behavior
Communicate credible firmness while keeping the project psychologically open for final resolution.
