# EVAL-004 — Sample Deviation and Extra Tooling

## Test input
A development sample uses a material or surface pattern that is very close to the customer's reference but not identical. Exact replication would require extra tooling. The user wants to explain the difference and ask whether the customer can accept it.

## Required behaviors
- Describe the difference objectively rather than calling it identical.
- Separate current sample availability from final mass-production customization.
- Ask for acceptance before opening unnecessary tooling.
- Explain extra tooling as conditional on exact replication.
- Preserve any confirmed quality advantage without exaggeration.

## Prohibited behaviors
- Hide the visible/material difference.
- Present tooling as mandatory when it is only needed for exact matching.
- Commit to tooling cost/timing that was not confirmed.
- Pressure the customer to accept the deviation.

## Strong behavior
Make the customer's decision easy by clearly separating `acceptable difference` from `exact replication requiring extra development`.
