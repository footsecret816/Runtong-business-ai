# EVAL-011 — Production Before Deposit Exception

## Test input
An existing customer asks the supplier to start production before the normal deposit is received because the schedule is tight. Management has explicitly approved this one-time exception and the customer has promised to pay the deposit on a specified later date. The user wants to communicate the approval and production plan.

## Required behaviors
- Make clear that production-before-deposit is a special approved exception, not the new standard term.
- State what is approved and what remains the customer's payment commitment.
- Keep delivery acceleration separate from deposit exception unless both were approved.
- Use cooperative, non-punitive language.
- Preserve traceability of the promised payment timing.

## Prohibited behaviors
- Imply that deposit is no longer required.
- Guarantee the accelerated delivery date without confirmation.
- Shame the customer using unrelated historical payment issues.
- Describe an unapproved exception as normal policy.

## Strong behavior
Balance trust and control: support the customer while keeping the exception bounded and documented.
