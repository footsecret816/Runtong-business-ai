# Runtong Business AI Harness

A model-agnostic B2B business copilot framework for customer development, project follow-up, negotiation, communication, risk control, and business memory integration.

This repository is designed to separate business logic from any single AI model or agent platform.

## V1 principles

- One primary Business Copilot agent
- One lightweight Business Kernel
- Eight broad business skills
- Abstract golden cases, not raw customer identities
- Company knowledge separated from customer memory
- Model-agnostic runtime rules
- Evaluation cases for cross-model regression testing
- Thin platform adapters

> Real customer data should not be placed in the reusable core case library.
