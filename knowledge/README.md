# Knowledge Layer

This directory stores reusable business knowledge that is separate from customer-specific memory.

Recommended categories:
- company profile and positioning,
- product capabilities,
- supplier/factory capability summaries,
- compliance and certification boundaries,
- SOP and workflow knowledge,
- communication style and business rules.

## Important boundaries
- Company-general capability does not automatically apply to every product or factory.
- Product/factory/certification facts should be scoped as narrowly as needed.
- Real customer histories, confidential prices, and project-specific commercial terms belong in a separate customer memory layer.

V1 keeps this layer intentionally light. Company-specific knowledge can be added after the core behavior is reviewed and accepted.
